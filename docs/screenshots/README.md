# 截图清单

上传前把下面这些图放进本目录，README 会自动引用前 5 张。

**统一要求：**
- 浏览器宽度 1440px 以上，缩放 100%
- 用测试数据，**不要出现真实姓名、真实金额、真实手机号**
- 深色或浅色主题只用一种，不要混
- 首图横向 16:9，其余四张统一尺寸（建议 1280×800）

| 文件名 | 截什么 | 要体现的点 |
|---|---|---|
| `01-home.png` | 首页看板（横向大图） | 整体质感，这是商品页首图 |
| `02-bills.png` | 账单列表 | 分类图标、金额、日期排布清楚 |
| `03-import.png` | 账单导入后的去重结果 | **最重要的一张**：能看出「同一笔被识别为一条」 |
| `04-settle.png` | 夫妻 AA 结算页 | 净额一目了然，不用手工算 |
| `05-report.png` | 月度报表 | 分类占比 / 趋势图 |
| `06-trip.png`（可选） | 差旅报销列表 | 按笔挂靠、报销回款单独归集 |
| `07-mobile.png`（可选） | 手机端 | 证明手机能用 |
| `08-backup.png`（可选） | 备份脚本输出 | 让技术买家放心 |

`03-import.png` 是这套系统唯一真正差异化的地方，值得单独做一张「导入前 vs 导入后」的对比图。
